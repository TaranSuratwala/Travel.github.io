# Travel.github.io

Landing page copy and markup for the "Automation University" waitlist.

## Highlights

- Single-page hero with CTA
- Feature list and value proposition
- Static HTML/CSS with Google Fonts

## Site Theme

The live theme is in `index.html` and `styles.css`. Enable GitHub Pages to publish from the root.

## How to Use

1. Open `index.html` in a browser.
2. Edit `index.html` and `styles.css` to adjust copy or visuals.

## Landing Page HTML

See `index.html` for the full markup and `styles.css` for the theme.
